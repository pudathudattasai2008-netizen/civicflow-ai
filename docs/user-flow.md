# 04 — User Flow

```text
Open CivicFlow
      ↓
What do you need help with?
      ↓
User describes request
      ↓
AI identifies possible service
      ↓
Service overview
      ↓
Eligibility
      ↓
Documents
      ↓
Step-by-step application
      ↓
Service center / online option
      ↓
Application tracking
```

## Example
User: "I need help applying for a birth certificate."

CivicFlow should guide the user through the relevant verified process rather than asking them to search through multiple pages.

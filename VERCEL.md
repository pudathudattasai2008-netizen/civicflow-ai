# Deploy CivicFlow on Vercel

1. Push this folder to the GitHub repository.
2. In Vercel, choose **Add New → Project** and import the GitHub repository.
3. Framework preset: **Vite** (or let Vercel detect it).
4. Build command: `npm run build`
5. Output directory: `dist`
6. Click **Deploy**.

The site is a frontend prototype. It uses demo service data and does not connect to live government systems.

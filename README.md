# CivicFlow

### AI-Powered Public-Service Navigation

CivicFlow is an AI-powered UX platform designed to make complex public-service processes simple, accessible, and easy to understand.

## Problem
Public-service processes can be difficult to understand. Users often struggle with finding the correct service, eligibility, required documents, application steps, status tracking, and nearby service centers.

## Solution
CivicFlow converts complicated public-service processes into a simple step-by-step experience.

## Key Features
- AI Service Guide
- Document Checklist
- Step-by-Step Journey
- Service Center Finder
- Application Tracking
- Accessibility Mode
- Multilingual Support
- Voice Assistance

## UX Process
Problem → Research → Personas → User Journey → Information Architecture → Wireframes → Design System → Prototype → AI → Accessibility → Frontend → Testing

## Project Status
✅ Interactive frontend prototype created.

The current prototype is a frontend-only demo with sample service data. It does not connect to live government systems or submit real applications.

## Structure
See the `docs/`, `design/`, `src/`, `ai/`, and `screenshots/` folders for the project workflow. The deployable frontend entry point is `index.html`, with app logic in `src/main.js` and styles in `src/styles.css`.
